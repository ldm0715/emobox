# Phase 24：设置页文案降噪 + 关于页开源依赖

> 2026-09。两个诉求：①设置页常驻文字太多（快捷键页尤甚，从未做过收纳），在「看得懂」的前提下藏起来；②关于页删掉「开发计划」，改为开源依赖署名（图标 + 名称，点击跳 GitHub）。

## 一、设置页文案全部收进 LabelInfo

Phase 19 已建立 `LabelInfo`（标题旁 `Info16Regular` + `Tooltip relationship="description"`）模式，但只有「用选中文字自动搜索」「联网下载网页 GIF」两行用了，且这两行还各自保留了一句常驻短说明。Phase 24 把该模式推广到**全部设置行**：

- **每行只留标题；说明文字全部进 Tooltip；标题本身自明的行连 Info 图标都不放**（默认启动页面、EmoBox 素材库路径行、支持格式）。
- 常规页：主题 / 关闭窗口时最小化到系统托盘 / 自动粘贴到原窗口 三行由常驻说明改为 LabelInfo；两条已迁移行的常驻短说明删除、与 Tooltip 原文合并。
- **快捷键页（重灾区）**：「快速搜索」「从剪贴板收藏」「打开快捷搜索浮层」三行全部改 LabelInfo。
- **存储页**：「导入与索引方式」的 42 字长句收进 Tooltip，并把底部隐私 MessageBar 的句子并入同一 Tooltip 后**删除 MessageBar**；`Badge「仅本地处理」`移到该卡片的控件位（原 inlineBadgeRow 样式删除）。
- 保留的非常驻文字都是**状态反馈**而非说明：ShortcutEditor 的已注册 statusLine、未注册警告、Alt+Space 冲突警告、错误 MessageBar——不收纳。

**ShortcutEditor 删除常驻 help 行**：原 `helpText` 默认文「快捷键必须包含 Ctrl、Alt、Shift 或 Win。也可以直接编辑文本后应用。」每个编辑器下都常驻一份，是快捷键页最显眼的噪音。已删除 `helpText` prop、`styles.help` 与渲染行；格式约束并入两个快捷键设置行 Tooltip 的末尾（「快捷键须包含 Ctrl、Alt、Shift 或 Win，可直接键入或点击「录制」」）。全仓库只有 SettingsMenu 两处使用该组件（已 grep 确认）。

- **新增「开源依赖」card**：flex-wrap 的 chip 按钮（20px 单色品牌图标 + 名称），hover 变品牌色描边。核心 6 项：Tauri / Rust / React / Fluent UI / Vite / TypeScript，点击跳对应 GitHub 仓库。

### 图标来源（`src/app/aboutDependencies.tsx`）

品牌图标以 **simple-icons（CC0）** 的 path 数据内嵌为单色 `currentColor` SVG（viewBox 0 0 24 24）——tauri / react / vite / typescript / rust 均已验证存在；**Fluent UI 未被 simple-icons 收录**，用手绘简化标（四瓣组合：圆角方块 / 圆 / 圆角方块 / 胶囊）兜底。单色方案避免暗色主题下品牌色不可辨（如 Rust 黑齿轮）。chip 样式注意：**原生 SVG 无默认尺寸**，必须由 CSS `& svg { width/height: 20px }` 控制大小；Griffel 不允许直接写 `borderColor` 键（hover 态要用整条 `border` 简写）。

## 三、打开外链的 Rust 通道

全应用此前**没有任何打开外部 URL 的能力**（无 opener/shell 插件，现有「打开」都是 explorer.exe 开本地目录）。选择**自写命令**而非引入 `tauri-plugin-opener`（少一个 npm/cargo 依赖，且与现有 `show_path_in_explorer` 模式一致）：

- `commands.rs::open_external_url(url) -> Result<(), String>`：`https://` 前缀校验 + host 白名单（目前仅 `github.com`，userinfo/端口剥除后比对）→ Windows `explorer.exe <url>`（默认浏览器），非 Windows `open`（与 show_path_in_explorer 同款双分支）。自定义命令不需要 capability。
- `lib.rs::invoke_handler` 注册（38 → 39）；`src/lib/tauri.ts` 加 `openExternalUrl()` 包装（唯一 invoke 出口惯例）。
- 调用失败走 `SettingsDialog` 新 prop `onNotifyError`（App 传入 `notifyError`）→ 右上角 error toast，符合统一通知模型。
